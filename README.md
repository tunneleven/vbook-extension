# vBook extensions

Kho extension vBook cho các nguồn tiểu thuyết tiếng Trung.

## Cài đặt

Thêm URL nguồn sau vào vBook:

```text
https://raw.githubusercontent.com/tunneleven/vbook-extension/main/plugin.json
```

## Extensions

- `xiaoshuo-tw` — Xiaoshuo TW (`xiaoshuo.com.tw`)
- `piaotia-com` — Piaotia (`piaotia.com`)
- `ttkan` — TTKan / 天天看小说 (`ttkan.co`)
